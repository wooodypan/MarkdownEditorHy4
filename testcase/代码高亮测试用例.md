# 代码高亮测试用例

支持的语言：**C / C++ / Objective-C / Java / C# / Kotlin / Go / Rust / Swift / JavaScript / TypeScript / Python / Ruby / PHP / Shell / SQL / JSON（含 JSONC）**，同一个语言的各种别名都认（```C++``` / ```cpp``` / ```cxx``` 一样）。其它语言（以及没写语言的）按纯文本显示。

把这份文档贴进编辑器，肉眼看颜色对不对就行。每条用例下面写了「该看到什么」。

## C

```c
#include <stdio.h>
#include <stdlib.h>

/* 块注释里的 int 不该被当成类型 */
#define MAX_COUNT 10

// 行注释
int main(void) {
    char *msg = "hello \"world\"";
    int n = 0x1F + 0b1010;
    double ratio = 3.14e-8;
    if (n > MAX_COUNT) {
        return EXIT_FAILURE;
    }
    printf("%s\n", msg);
    return 0;
}
```

该看到：`#include` / `#define` 紫色（预处理指令）；`int` / `void` / `char` / `double` 青色（类型）；`if` / `return` 紫色；`"hello \"world\""` 红色；`0x1F` / `0b1010` / `3.14e-8` 蓝色；`main` / `msg` / `printf` 保持正文色（不上色）。

## C++

```cpp
#pragma once
#include <vector>

// 模板里的 typename 也要认出来
template <typename T>
class Widget {
public:
    explicit Widget(int size) : size_(size) {}
    T *get() const noexcept { return nullptr; }

private:
    bool ready_ = false;
    int size_ = 0;
};

int main() {
    auto w = Widget<double>(1);
    std::vector<int> xs{1, 2, 3};
    return 0;
}
```

该看到：`class` / `template` / `public` / `private` / `noexcept` 紫色；`int` / `bool` / `double` / `void` 青色；`Widget` 青色（大写开头当类型）；`nullptr` / `true` / `false` 蓝色（字面量）；`#pragma` / `#include` 紫色。

## Objective-C

```objc
#import <Foundation/Foundation.h>

@interface Person : NSObject
@property (nonatomic, copy) NSString *name;
@property (nonatomic, assign) NSInteger age;

- (NSString *)greet;
@end

@implementation Person
- (NSString *)greet {
    // 字符串字面量前面那个 @ 也要算进字符串色
    return [NSString stringWithFormat:@"hi %@", self.name];
}
@end
```

该看到：`#import` 紫色；`@interface` / `@property` / `@end` / `@implementation` 紫色（`@` 和后面的词整词一起上色）；`@"hi %@..."` 整段（**含开头的 `@`**）红色；`NSString` / `NSObject` / `NSInteger` 青色；`nil` / `YES` / `NO` / `self` / `super` 蓝色。

## Java

```java
package com.example.demo;

import java.util.List;
import java.util.ArrayList;

@Override
public class Demo<T> {
    private static final int MAX = 0x1F;

    // 注解按类型色上（青色），不是关键字色
    @SuppressWarnings("unchecked")
    public void run() {
        var list = new ArrayList<String>();
        long count = 10_000L;
        double ratio = 3.14e-8;
        if (list.isEmpty()) {
            System.out.println("empty");
        }
    }
}
```

该看到：`public` / `class` / `private` / `static` / `final` / `if` / `return` 紫色；`int` / `long` / `double` / `void` / `var` 青色（类型）；`@Override` / `@SuppressWarnings` 青色（注解走类型色）；`"empty"` 红色；`Demo` / `ArrayList` / `String` 青色。

## C#

```csharp
using System;

#region 入口

public class Counter
{
    private int _n = 0;

    // 插值字符串：$ 要和字符串一起上色
    public string Label => $"count is {_n}";

    public bool Ready => true;
}

#endregion
```

该看到：`#region` / `#endregion` 紫色（预处理指令）；`public` / `class` / `private` 紫色；`int` / `string` / `bool` 青色；`$"count is {_n}"` 整段（**含 `$`**）红色；`true` 蓝色。

## Kotlin

```kotlin
@JvmStatic
fun classify(n: Int): String = when {
    n > 0 -> """
        三引号字符串里的 fun / val 都不算关键字
        """
    else -> "非正数"
}

val items = listOf(1, 2, 3)
```

该看到：`fun` / `when` / `else` / `val` 紫色；`Int` / `String` 青色；`@JvmStatic` 青色；三引号里那句 `fun / val` **应该是红色**（它是字符串内容）；`"非正数"` 红色。

## Go

```go
package main

import "fmt"

// 大写开头在 Go 里表示「导出」，不是类型，所以 Println 不上青色
func sum(xs []int) int {
	total := 0
	for _, x := range xs {
		total += x
	}
	return total
}

func main() {
	raw := `原始字符串可以跨行
	里面的 func / return 都不算关键字`
	fmt.Println(raw, sum([]int{1, 2, 3}))
}
```

该看到：`func` / `package` / `import` / `for` / `range` / `return` 紫色；`int` / `string` / `error` 青色；`Println` **保持正文色**（不上青色）；反引号那段（**跨两行**）整段红色。

## Rust

```rust
use std::collections::HashMap;

// 生命周期标记 'a 千万不能被当成单引号字符串
fn first<'a>(text: &'a str) -> &'a str {
    let n: u8 = 1;
    let mut map: HashMap<String, i32> = HashMap::new();
    map.insert("k".to_string(), 42);
    text
}
```

该看到：`use` / `fn` / `let` / `mut` / `return` 紫色；`u8` / `i32` / `str` 青色；`'a` **不能是红色**（关掉了单引号字符串，就是为了这个）；`"k"` 红色；`HashMap` 青色。

## Swift

```swift
import Markdown

// 只有标题层级折叠
let document = Document(parsing: markdown)
for child in document.children {
    print(type(of: child))
}

/* 块注释里写 let 也不该被当成关键字：
   这是一段多行注释 */
final class EditorViewController: UIViewController {
    private static let maximumHeight: CGFloat = 0x1F * 2
    var count: Int = 42
    var ratio: Double = 3.14e-8
    var name = "含有 \"引号\" 的字符串"
    var multi = """
    三引号字符串里的 if / return 都不算关键字
    """
}
```

该看到：`final` / `class` / `private` / `static` / `let` / `var` / `for` / `in` / `return` 紫色；`Int` / `Double` / `CGFloat` 青色；`"…"` 红色；三引号那段整段红色（里面的 `if` 不该变紫）。

## JavaScript

```js
// 行注释
const numbers = [1, 2, 3];
let total = 0xFF + 0b1010;
/* 块注释 */
function format(user) {
    return `hello ${user.name}, you have ${numbers.length} items`;
}
class DocumentView extends UIView {
    render() { return true; }
}
```

该看到：`const` / `let` / `function` / `return` / `class` / `extends` 紫色；`0xFF` / `0b1010` 蓝色；反引号模板串整段红色（`${…}` 不单独上色）；`true` 蓝色。

## TypeScript

```ts
interface User {
    name: string;
    age: number;
}

const u: User = { name: "a", age: 1 };
type Keys = keyof User;

export function pick<T, K extends keyof T>(o: T, k: K): T[K] {
    return o[k];
}
```

该看到：`interface` / `const` / `type` / `keyof` / `export` / `function` / `extends` / `return` 紫色；`string` / `number` 青色（小写类型名靠类型表认出来）；`User` 青色；`"a"` 红色。

## Python

```python
# Python 的注释用井号
import os


def greet(name, times=3):
    """三引号（docstring）里的 return 也不该被当成关键字"""
    doc = """
    多行字符串：if x > 0
    """
    prefix = f"hi {name} " 'and'
    for _ in range(times):
        print(prefix, os.sep, 1_000, 0.5e3, 3j)
    return True


class Document:
    def __init__(self):
        self.title = '单引号字符串'
```

该看到：`# …` 灰绿；`def` / `import` / `for` / `in` / `return` / `class` 紫色；三引号段落整段红色；`f"hi {name} "` 红色（前缀 `f` 也算进去）；`True` / `None` 蓝色。

## Ruby

```ruby
# 行注释
class Greeter
  def hello(name)
    # 字符串插值里的 # 不能被当成注释
    puts "hi #{name}"
    :symbol_value
  end
end

items = [1, 2, 3].map { |x| x * 2 }
```

该看到：`# …` 灰绿；`class` / `def` / `end` / `puts` 紫色；`"hi #{name}"` 整段红色；`Greeter` 青色。

## PHP

```php
<?php
// 行注释

# 井号也是行注释（PHP 两种都认）

function greet($name) {
    $text = "hi $name";
    echo $text;
    return true;
}
```

该看到：`// …` 和 `# …` **两种都**是灰绿；`function` / `echo` / `return` 紫色；`"hi $name"` 整段红色；`true` 蓝色。⚠️ `$name` / `$text` 保持正文色（PHP 变量不上色，这是刻意的性能取舍）。

## Shell

```bash
#!/bin/bash
# 部署脚本

set -euo pipefail

if [ -f "$FILE" ]; then
    echo "找到文件"
else
    echo "没找到" >&2
    exit 1
fi
```

该看到：`#!/bin/bash` 和 `# …` 都是灰绿（shebang 按注释走）；`if` / `then` / `else` / `fi` / `set` / `echo` / `exit` 紫色；`"$FILE"` / `"找到文件"` 红色。

## SQL

```sql
-- 行注释（两种大小写都要认）

SELECT id, name FROM users WHERE age > 18 ORDER BY id LIMIT 10;

select count(*) from orders where status = 'paid';

CREATE TABLE report (
    id INT PRIMARY KEY,
    title VARCHAR(20),
    created_at TIMESTAMP
);
```

该看到：`-- …` 灰绿；`SELECT` 和 `select`、`FROM` 和 `from`、`WHERE` 和 `where` **一样是紫色**（SQL 不分大小写）；`INT` / `int` / `VARCHAR` / `TIMESTAMP` 青色（同样不分大小写）；`'paid'` 红色；`18` / `10` 蓝色；表名 `users` / `report` **保持正文色**（SQL 关掉了「大写开头当类型」，不然 `USER_ID` 这种列名会满屏颜色）。

## JSON

```json
{
  "name": "demo",
  "count": 3,
  "enabled": true,
  "extra": null,
  "nested": { "deep": [1, 2.5] }
}
```

该看到：键和值（`"name"` / `"demo"` …）都是红色；`3` / `2.5` 蓝色；`true` / `null` 蓝色。JSON **没有注释**，`//` 不会被当注释吞掉。

## JSONC（带注释的 JSON）

```jsonc

```

该看到：两种注释都是灰绿；`"a"` / `"b"` 红色；`true` 蓝色。
