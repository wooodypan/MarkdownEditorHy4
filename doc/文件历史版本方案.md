# Markdown 本地历史版本方案

作者：Claude Sonnet 5.5

## 一、整体思路(先看这个)

**每次需要留档时,把文件完整内容存成一份快照,再用一个清单文件记录所有快照的信息。**

流程:

```
用户编辑 → 满足触发条件 → 计算内容哈希 → 与最新版本相同?
                                    ├─ 是:什么都不做
                                    └─ 否:写入快照文件 → 更新清单 → 按规则清理旧版本
```

查看、对比、恢复都基于这些快照,UI 层只调用下面的 `HistoryStore`。

### 为什么存完整快照,而不是只存差异(diff)

|  | 完整快照 | 只存差异 |
| --- | --- | --- |
| 实现难度 | 很简单 | 复杂,要按顺序"回放"差异 |
| 可靠性 | 任意一份损坏不影响其他 | 链条中一环损坏,后面全部无法还原 |
| 对比任意两个版本 | 直接取出两份文本对比 | 需要先还原 |
| 空间 | 占用大一点 | 省空间 |

Markdown 文件通常只有几 KB 到几百 KB,配合后面的"清理策略",空间完全不是问题。**初级团队首选快照。**

### 存储位置方案对比

| 方案 | 说明 | 结论 |
| --- | --- | --- |
| 文件 + JSON 清单 | 每个版本一个 `.md`,一个 `manifest.json` 做索引 | **推荐**:无依赖,易调试 |
| SQLite / SwiftData / Core Data | 内容和元数据都进数据库 | 可行,但对这个需求偏重 |
| 内嵌 Git(libgit2) | 功能最强 | 过重,不推荐 |

下面按"文件 + JSON 清单"来讲。

## 二、目录结构

存放在 `Application Support` 目录。不要放 `Caches` 或 `tmp`,系统空间不足时会清掉那里的内容。

```
Application Support/
└── MarkdownHistory/
    ├── 3F2A9C...(文档A的ID)/
    │   ├── manifest.json            ← 版本清单
    │   ├── 8B1D...-....md           ← 版本1的内容
    │   └── C47E...-....md           ← 版本2的内容
    └── 91AB...(文档B的ID)/
        └── ...
```

**关键点:用"文档 ID"(UUID)作为文件夹名,不要用文件名或路径。** 用户重命名、移动文件后,历史记录仍然能对上。你的文档模型里需要存一个固定的 `id`。代码接口也直接收 `UUID`,文件夹名统一用 `uuidString` 拼,调用方没有机会传进 `..`、`/` 或空字符串,`deleteHistory` 也就只可能删掉 `MarkdownHistory` 下面的某一个文档目录。

## 三、数据模型

```swift
import Foundation

struct VersionMeta: Codable, Identifiable, Equatable {
    enum Reason: String, Codable {
        case autoSave        // 停止输入后自动留档
        case appBackground   // 退到后台/离开页面时留档
        case manual          // 用户手动"保存版本"(永久保留)
        case beforeRestore   // 恢复旧版本之前,给当前内容留的后悔药
    }

    let id: UUID
    let sequence: Int          // 自增编号(像排队取号),谁大谁新。判断"新旧"只看它
    let createdAt: Date        // 只用来显示,不参与任何判断
    let contentHash: String
    let byteCount: Int
    var reason: Reason         // 用 var:自动版本可以被"转正"为手动版本
    var note: String?

    var fileName: String { "\(id.uuidString).md" }
}

struct Manifest: Codable {
    var schemaVersion = 1
    var nextSequence = 1       // 下一个要发的编号
    var versions: [VersionMeta] = []

    /// 最新版本在数组里的位置(sequence 最大的那个)
    var latestIndex: Int? {
        versions.indices.max { versions[$0].sequence < versions[$1].sequence }
    }
    var latest: VersionMeta? { latestIndex.map { versions[$0] } }
}

struct RetentionPolicy {
    var maxCount = 50                    // 只保留最近 N 个版本
    var manualVersionsExempt = true      // true:手动版本永久保留,且不占 N 的名额
}

/// 恢复的结果:内容一定有;safetyBackupError 非 nil 表示"恢复前的备份没存上"
struct RestoreResult {
    let content: String
    let safetyBackupError: Error?
}

enum HistoryError: LocalizedError {
    case versionNotFound
    case corruptedContent
    case manifestUnreadable(underlying: Error)

    var errorDescription: String? {
        switch self {
        case .versionNotFound: return "找不到这个历史版本"
        case .corruptedContent: return "历史版本文件已损坏"
        case .manifestUnreadable(let e): return "历史记录清单无法读取:\(e.localizedDescription)"
        }
    }
}
```

## 四、核心类 HistoryStore

用 `actor` 实现,它能保证同一时间只有一个任务在读写,避免两个线程同时改清单造成数据错乱。

```swift
import Foundation
import CryptoKit
import os

actor HistoryStore {
    private let rootURL: URL
    private let policy: RetentionPolicy
    private let fm = FileManager.default
    private let log = Logger(subsystem: "MarkdownHistory", category: "HistoryStore")

    init(rootURL: URL, policy: RetentionPolicy = RetentionPolicy()) {
        self.rootURL = rootURL
        self.policy = policy
    }

    static func defaultRootURL() throws -> URL {
        try FileManager.default
            .url(for: .applicationSupportDirectory, in: .userDomainMask,
                 appropriateFor: nil, create: true)
            .appendingPathComponent("MarkdownHistory", isDirectory: true)
    }

    // MARK: - 对外接口

    /// 自动留档(autoSave / appBackground / beforeRestore)。
    /// 内容与最新版本相同时返回 nil。protecting 里的版本不会被本次清理删除。
    @discardableResult
    func saveSnapshot(docID: UUID,
                      content: String,
                      reason: VersionMeta.Reason,
                      protecting: Set<UUID> = []) throws -> VersionMeta? {
        var manifest = try loadManifest(docID)
        let hash = Self.sha256(content)
        if manifest.latest?.contentHash == hash { return nil }   // 去重
        return try append(content: content, hash: hash, reason: reason, note: nil,
                          to: &manifest, docID: docID, protecting: protecting)
    }

    /// 手动"保存版本":绝不会什么都不留下。
    /// - 内容与最新版本相同:把最新版本"转正"为手动版本(不产生重复文件)
    /// - 否则:新建一个手动版本
    @discardableResult
    func saveManualVersion(docID: UUID,
                           content: String,
                           note: String? = nil) throws -> VersionMeta {
        var manifest = try loadManifest(docID)
        let hash = Self.sha256(content)

        if let idx = manifest.latestIndex, manifest.versions[idx].contentHash == hash {
            manifest.versions[idx].reason = .manual
            if let note { manifest.versions[idx].note = note }
            try saveManifest(manifest, docID)
            return manifest.versions[idx]
        }
        return try append(content: content, hash: hash, reason: .manual, note: note,
                          to: &manifest, docID: docID, protecting: [])
    }

    /// 版本列表,最新的在前
    func listVersions(docID: UUID) throws -> [VersionMeta] {
        try loadManifest(docID).versions.sorted { $0.sequence > $1.sequence }
    }

    /// 读取某个版本的正文
    func content(docID: UUID, versionID: UUID) throws -> String {
        let manifest = try loadManifest(docID)
        guard let meta = manifest.versions.first(where: { $0.id == versionID }) else {
            throw HistoryError.versionNotFound
        }
        let url = try documentDir(docID).appendingPathComponent(meta.fileName)
        guard let text = String(data: try Data(contentsOf: url), encoding: .utf8) else {
            throw HistoryError.corruptedContent
        }
        return text
    }

    /// 恢复到某个版本。顺序很重要:
    /// 1. 先把目标版本读出来(读不到就直接抛错,此时什么都没改动)
    /// 2. 再给当前内容留后悔药,并把目标版本放进保护名单,防止被清理
    /// 3. 后悔药保存失败也要完成恢复,只是通过 safetyBackupError 告诉调用方
    func restore(docID: UUID, versionID: UUID, currentContent: String) throws -> RestoreResult {
        let target = try content(docID: docID, versionID: versionID)

        var backupError: Error?
        do {
            try saveSnapshot(docID: docID, content: currentContent,
                             reason: .beforeRestore, protecting: [versionID])
        } catch {
            backupError = error
            log.error("恢复前备份失败: \(error.localizedDescription, privacy: .public)")
        }
        return RestoreResult(content: target, safetyBackupError: backupError)
    }

    func deleteHistory(docID: UUID) throws {
        // UUID 只会拼出 rootURL 下的一层,不可能删到 Application Support 本身
        let dir = rootURL.appendingPathComponent(docID.uuidString, isDirectory: true)
        if fm.fileExists(atPath: dir.path) { try fm.removeItem(at: dir) }
    }

    // MARK: - 内部:新增一个版本(写文件 → 清理 → 写清单 → 删旧文件)

    private func append(content: String, hash: String,
                        reason: VersionMeta.Reason, note: String?,
                        to manifest: inout Manifest, docID: UUID,
                        protecting: Set<UUID>) throws -> VersionMeta {
        let data = Data(content.utf8)
        let meta = VersionMeta(id: UUID(), sequence: manifest.nextSequence,
                               createdAt: Date(), contentHash: hash,
                               byteCount: data.count, reason: reason, note: note)
        let dir = try documentDir(docID)
        let newFile = dir.appendingPathComponent(meta.fileName)
        try data.write(to: newFile, options: .atomic)

        manifest.nextSequence += 1
        manifest.versions.append(meta)

        let doomed = Self.versionsToDelete(manifest.versions, policy: policy, protected: protecting)
        manifest.versions.removeAll { doomed.contains($0.id) }

        do {
            try saveManifest(manifest, docID)
        } catch {
            try? fm.removeItem(at: newFile)   // 清单没写成,刚写的文件就是孤儿,顺手清掉
            throw error
        }

        // 清单已更新,删文件失败只会留下孤儿文件,不影响正确性,记日志即可
        for id in doomed {
            do { try fm.removeItem(at: dir.appendingPathComponent("\(id.uuidString).md")) }
            catch { log.error("删除旧版本文件失败: \(error.localizedDescription, privacy: .public)") }
        }
        return meta
    }

    /// 清理规则(纯函数,方便单测):只保留最近 N 个,保护名单里的不删
    static func versionsToDelete(_ versions: [VersionMeta],
                                 policy: RetentionPolicy,
                                 protected: Set<UUID> = []) -> Set<UUID> {
        let countable = versions
            .filter { !(policy.manualVersionsExempt && $0.reason == .manual) }
            .sorted { $0.sequence > $1.sequence }            // 新 → 旧
        let overflow = countable.dropFirst(policy.maxCount)  // 排在 N 名之后的都是更旧的
        return Set(overflow.map(\.id)).subtracting(protected)
    }

    // MARK: - 内部:文件读写

    private func documentDir(_ docID: UUID) throws -> URL {
        // UUID 拼出来只有一个路径段,不存在 ..、/ 或空串
        let dir = rootURL.appendingPathComponent(docID.uuidString, isDirectory: true)
        if !fm.fileExists(atPath: dir.path) {
            try fm.createDirectory(at: dir, withIntermediateDirectories: true)
        }
        return dir
    }

    private func manifestURL(_ docID: UUID) throws -> URL {
        try documentDir(docID).appendingPathComponent("manifest.json")
    }

    private func loadManifest(_ docID: UUID) throws -> Manifest {
        let url = try manifestURL(docID)
        guard fm.fileExists(atPath: url.path) else { return Manifest() }   // 第一次使用
        do {
            let decoder = JSONDecoder()
            decoder.dateDecodingStrategy = .iso8601
            return try decoder.decode(Manifest.self, from: Data(contentsOf: url))
        } catch {
            throw HistoryError.manifestUnreadable(underlying: error)
        }
    }

    private func saveManifest(_ manifest: Manifest, _ docID: UUID) throws {
        let encoder = JSONEncoder()
        encoder.dateEncodingStrategy = .iso8601   // 秒级精度没关系:时间只用于显示
        encoder.outputFormatting = [.prettyPrinted, .sortedKeys]
        try encoder.encode(manifest).write(to: manifestURL(docID), options: .atomic)
    }

    static func sha256(_ text: String) -> String {
        SHA256.hash(data: Data(text.utf8)).map { String(format: "%02x", $0) }.joined()
    }
}
```

## 五、什么时候留档(触发时机)

这是最容易做错的地方:**留档太频繁会产生大量垃圾版本,太少又会丢内容。** 推荐组合:

| 触发时机 | reason | 说明 |
| --- | --- | --- |
| 用户停止输入 30 秒 | `.autoSave` | 防抖,一直在打字时不会留档 |
| App 退到后台 | `.appBackground` | 随时可能被系统杀掉,必须立刻留档 |
| 关闭/离开编辑页 | `.autoSave` | 保证最后的修改被记录 |
| 用户点"保存版本" | `.manual` | 永不被自动清理 |
| 恢复旧版本之前 | `.beforeRestore` | 已在 `restore` 里自动处理 |

防抖逻辑封装成一个小类:

```swift
import Foundation
import os

@MainActor
final class HistoryCoordinator {
    private let store: HistoryStore
    private let docID: UUID
    private var debounceTask: Task<Void, Never>?
    private let idleSeconds: UInt64 = 30
    private let log = Logger(subsystem: "MarkdownHistory", category: "Coordinator")

    /// 自动留档失败时回调。UI 可以选择显示一个不打扰的提示(比如小图标),也可以不处理
    var onAutoSaveFailure: ((Error) -> Void)?

    init(store: HistoryStore, docID: UUID) {
        self.store = store
        self.docID = docID
    }

    /// 编辑器内容每次变化时调用
    func contentDidChange(_ text: String) {
        debounceTask?.cancel()
        debounceTask = Task { [weak self, idleSeconds] in
            // 这里的 try? 只用来吞掉"被取消"这一种预期内的错误,是有意为之
            try? await Task.sleep(nanoseconds: idleSeconds * 1_000_000_000)
            guard !Task.isCancelled, let self else { return }
            await self.autoSave(text, reason: .autoSave)
        }
    }

    /// 进入后台/离开页面时调用。此时没有界面可以弹窗,所以失败只记日志 + 回调
    func snapshotOnLeave(_ text: String, reason: VersionMeta.Reason = .appBackground) async {
        debounceTask?.cancel()
        await autoSave(text, reason: reason)
    }

    /// 用户点"保存版本":失败必须抛出,由界面明确提示用户
    func saveManualVersion(_ text: String, note: String? = nil) async throws -> VersionMeta {
        let version = try await store.saveManualVersion(docID: docID, content: text, note: note)
        debounceTask?.cancel()   // 保存成功后才取消,失败时自动留档的计时还在
        return version
    }

    private func autoSave(_ text: String, reason: VersionMeta.Reason) async {
        do {
            try await store.saveSnapshot(docID: docID, content: text, reason: reason)
        } catch {
            log.error("自动留档失败: \(error.localizedDescription, privacy: .public)")
            onAutoSaveFailure?(error)
        }
    }
}
```

进入后台的监听:SwiftUI 用 `@Environment(\.scenePhase)`,`.background` 时调用 `snapshotNow`;UIKit 监听 `UIApplication.willResignActiveNotification` 或 `didEnterBackgroundNotification`。

## 六、使用示例

```swift
// 手动保存:失败要提示
do {
    let v = try await coordinator.saveManualVersion(editorText)
    showToast("已保存版本 #\(v.sequence)")
} catch {
    showAlert("保存版本失败:\(error.localizedDescription)")
}

// 恢复:成功后要看一眼 safetyBackupError
let result = try await store.restore(docID: doc.id, versionID: picked.id, currentContent: editorText)
editorText = result.content
if result.safetyBackupError != nil {
    showAlert("已恢复,但恢复前的内容没能备份,刚才的修改可能无法找回。")
}
```

## 七、注意事项和边界情况

1. **原子写入**:`.atomic` 选项会先写临时文件再替换,即使写到一半 App 崩溃或没电,也不会留下半截损坏的文件。
2. **写入顺序是故意设计的**:新增时"先写内容文件,再改清单";删除时"先改清单,再删文件"。最坏情况是崩溃后留下一个没人引用的文件(浪费一点空间),但**清单里永远不会指向不存在的文件**。
3. **用户删除文档**:要调用 `deleteHistory`,否则历史会一直占空间。也可以做"回收站"策略,延迟 30 天再删。
4. **文本编码**:统一按 UTF-8 存取。读取外部文件时遇到非 UTF-8 编码要先转换。
5. **超大文件**:Markdown 一般很小。如果允许几十 MB 的文件,可以把 `maxCount` 调低,或用 `(data as NSData).compressed(using: .lzfse)` 压缩后再存。
6. **备份**:`Application Support` 默认会进 iCloud/iTunes 备份,换手机后历史还在,通常符合预期。不想备份可对目录设置 `isExcludedFromBackup`。
7. **清单损坏**:`manifest.json` 解析失败时,可以做成"遍历文件夹里的 `.md` 文件,按文件创建时间重建清单"的兜底,初版可以先不做,但要知道有这个办法。
8. **多进程**:`actor` 只保证同一个 App 进程内安全。如果你还有 Share Extension、Widget 等要读写同一份历史,需要放到 App Group 共享目录,并额外处理并发。

## 八、测试清单

用临时目录创建 `HistoryStore`,逐条写单元测试:

- 保存相同内容两次,只产生 1 个自动版本(去重仍然有效)。
- 自动版本 A 之后,用相同内容调用 `saveManualVersion`,版本总数不变,A 的 `reason` 变成 `.manual`。
- 手动版本连续保存两次,不报错,版本总数不变。
- 一秒内连续保存多个版本,`listVersions` 顺序稳定,`sequence` 严格递增。
- 存满 N 个版本后,恢复**最旧**的那个:能成功读出内容,恢复前的备份也已保存(这是问题 1 的回归测试)。
- `versionsToDelete` 的纯函数测试:超过 N 的最旧版本被删,保护名单里的不删,手动版本不删也不占名额。
- 把目录设为只读后调用保存:`saveSnapshot` 抛错,`saveManualVersion` 抛错,`restore` 返回的 `safetyBackupError` 非空。
- 手动破坏 `manifest.json` 内容:保存时抛出 `manifestUnreadable`。

`versionsToDelete` 是纯函数(传入数据、返回结果,不碰文件系统),最适合先单独测试。

## 九、实施步骤

1. 给文档模型加固定的 `id`(UUID)。
2. 把第三、四部分的代码放进项目,先写测试跑通。
3. 接入触发时机:防抖、进入后台、手动保存。
4. 做历史列表页(用 `listVersions`),点击后预览(用 `content`)。
5. 接入前面讲过的 diff 对比,和恢复功能。
6. 在删除文档的流程里加上 `deleteHistory`。
